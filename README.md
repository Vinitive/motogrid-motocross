# MotoGrid Motocross Website

Responsive static website for the MotoGrid motocross brand, built around a black, white, and lime-green racing identity.

## Pages
- `index.html` — homepage
- `shop.html` — concept collection (not a live store)
- `riders.html` — rider community
- `about.html` — brand story
- `contact.html` — contact form that opens an email app

## Publish
Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. Replace `YOUR-EMAIL-HERE` in `assets/script.js` with your contact email.

No build step required. This starter does not include payment processing or inventory.
